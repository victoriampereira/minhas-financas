# Minhas Finanças

App pessoal de finanças (renda, contas fixas, cartões com faturas e parcelas, reserva).

- Página única: `index.html` (HTML + CSS + JS no mesmo arquivo)
- Ícones em `icons/` e visuais dos cartões em `icons/cards/`
- Dados salvos no Supabase (tabela `fin_docs`), protegidos por login — nada de dados pessoais fica neste repositório
- Publicado pelo GitHub Pages: https://victoriampereira.github.io/minhas-financas/
